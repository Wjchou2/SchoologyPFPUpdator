# SchoologyPFPUpdator
Small python script that updates your pfp, this exmaple uploads a clock image with current time, but you can use it to put any image. 

set .env with 4 vars

export SCHOOLOGY_USER_ID="131377286"

export SCHOOLOGY_CSRF_KEY="YOUR_KEY"

export SCHOOLOGY_CSRF_TOKEN="YOUR_TOKEN"

export SCHOOLOGY_COOKIE='YOUR_FULL_COOKIE'


these can be found on network tab when making a pfp change call on schoology

designed to run on rpi/mac
